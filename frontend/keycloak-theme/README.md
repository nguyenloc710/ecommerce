# keycloak-theme

Theme trang đăng nhập và trang tài khoản của Keycloak, viết bằng [Keycloakify](https://www.keycloakify.dev/) (React), đồng bộ thương hiệu với storefront, mặc định tiếng Việt.

Chưa khởi tạo. Làm ở giai đoạn 2 (go-live) theo `docs/ke-hoach-thiet-ke.md` mục 15. Build ra file `.jar` theme rồi đóng gói vào image Keycloak tùy biến (xem mục 10).
